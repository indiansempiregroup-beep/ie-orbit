To run the OPS-Mobile (phone on same Wi-Fi / hotspot — use your PC LAN IP, not localhost)

cd "D:\Indians Empire\IE Platform\ie-platform\apps\ops-mobile"
$env:REACT_NATIVE_PACKAGER_HOSTNAME="172.20.10.14"
$env:EXPO_PUBLIC_API_BASE_URL="http://172.20.10.14:8000/api/v1"
pnpm.cmd start -- --clear --lan

# QR should show exp://172.20.10.14:8082 (NOT 127.0.0.1)

# If login shows "Network request failed":
# 1) On your iPhone Safari open: http://172.20.10.14:8000/api/v1/auth/login
#    - If Safari also fails, Windows Firewall is blocking the phone (most common).
# 2) Open PowerShell as Administrator and run:
#    New-NetFirewallRule -DisplayName "IE Platform Backend 8000" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8000 -Profile Any
# 3) Restart Expo with the env vars above, then reload the app.

# If LAN still fails, use tunnel instead:
# pnpm.cmd exec expo start --port 8082 --clear --tunnel
